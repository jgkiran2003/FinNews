# requirements-pinned.txt
# Single, consolidated, pinned dependency set for FinNews.
# Known-good on Python 3.11 (and 3.12). These versions are mutually compatible:
#   transformers 4.57.x requires accelerate>=0.26.0; pin 1.1.x satisfies it.
#   torch 2.4.x has stable cp311/cp312 Windows wheels.
# Install via:  python -m pip install -r requirements-pinned.txt

# ── Deep learning (pinned together — they must move as a set) ─────────────
# IMPORTANT: torch is NOT listed here. It must be installed SEPARATELY for
# GPU vs CPU — `pip install torch` gives a CPU-only wheel on Windows.
#
#   NVIDIA GPU (CUDA 12.8+ — required for RTX 50-series/Blackwell):
#     pip install torch --index-url https://download.pytorch.org/whl/cu128
#
#   CPU-only (smaller, no GPU):
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# setup_env.ps1 detects your GPU via nvidia-smi and installs the right one.
# (If torch were listed here, `pip install -r` would pull the default CPU
#  wheel and overwrite the GPU build — that's why it's excluded.)
